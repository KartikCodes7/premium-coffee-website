## 2. Site Vision
An AI-powered Restaurant Operating System (RestaurantOS) combining modern SaaS visuals, premium restaurant brand storytelling, and interactive AI widgets. Visually premium, high-contrast typography, and smooth page entry animations.

## 3. Pages & Features Roadmap
- [x] **Homepage (index)** — Cinematic hero section, visual menus, booking callout, floating chatbot trigger, WhatsApp direct CTA.
- [x] **Dashboard (dashboard)** — Admin dashboard, sales graphs, live orders tracker, AI automated replies management, settings.
- [x] **AI Chatbot (chatbot)** — Floating chat panel, smart AI restaurant assistant, context recommendations.
- [x] **Ordering Flow (order)** — Clean multi-step cart, food item details modal, receipt preview.
- [x] **Admin Analytics (analytics)** — High-density tables, popular items bar chart, repeat customers cohort grid.
- [x] **Authentication (login)** — Sleek sign-in and onboarding card pages.
